# Inform user that split-region generation has started

Inform user that split-region generation has started

## Usage

``` r
.inform_split_region_start(bed, gtf, output_bed, limit, shift_by, clearance)
```

## Arguments

- bed:

  BED input path.

- gtf:

  GTF input path.

- output_bed:

  Output BED path.

- limit:

  Maximum interval width.

- shift_by:

  Boundary shift step size.

- clearance:

  Boundary clearance distance.

## Value

Invisible `TRUE`.
