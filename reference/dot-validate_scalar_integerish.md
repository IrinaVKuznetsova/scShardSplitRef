# Validate and coerce a scalar integer-like numeric argument

Validate and coerce a scalar integer-like numeric argument

## Usage

``` r
.validate_scalar_integerish(x, arg, min_value)
```

## Arguments

- x:

  Value to validate.

- arg:

  Argument name used in error messages.

- min_value:

  Minimum permitted value.

## Value

Integer scalar.
